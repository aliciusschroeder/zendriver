## Lens: reproduce (verdict confirmed, realism medium, severity wrong-result)

### Summary
Every Tab misc member reproduces against real headless Chromium. get_all_urls resolves against the origin and drops bare-relative and '#' links. set_user_agent without metadata wipes navigator.userAgentData. download_file breaks (and can be injected into) on a quote in the url or filename and still returns normally. save_snapshot written with Windows text-mode newline semantics produces \r\r\n, and the page renders blank. save_screenshot(format='webp') raises UnboundLocalError. A7.12: the leak claim rests on code reading plus a live handle from an equivalent raw call.

## Lens: fixsafety (verdict confirmed, realism medium, severity crash)

### Summary
All 7 distinct Tab bugs reproduce on real headless Chromium 141, except A7.8, which is Windows-only and was reproduced by emulating Windows text mode plus a Chromium render check. (1) get_all_urls joins against scheme://host and drops bare relative links and any value containing '#'. (2) set_user_agent without metadata empties navigator.userAgentData, headless and headful. (3) download_file %-formats url and filename into JS: a quote silently does nothing, and a crafted filename runs JS. (4) save_snapshot text mode turns CRLF into CRCRLF on Windows, which renders blank. (5) save_screenshot(format='webp') raises UnboundLocalError. (6) Two auto-named screenshots in the same second share one path. (7) print_to_pdf(transfer_mode='ReturnAsStream') writes 0 bytes.

### Refinements
get_all_urls should resolve against document.baseURI so that <base href> is honoured, which the prototype does. Anchors made only of '#' are still skipped as in-page links. The old filter also accepted javascript:, mailto: and data: values only when they contained '/', and the urljoin+startswith filter still drops those. A7.6 needs a design decision for headful mode: there is no stored metadata to reuse. Reading navigator.userAgentData.getHighEntropyValues only works in secure contexts. Sending user_agent='' keeps the hints but drops a custom UA the caller set earlier, and in headless it restores HeadlessChrome. So the prototype only fixes the case where the current UA equals browser.headless_user_agent[0], which is the regression the CHANGELOG fix was meant to remove. A7.7's injection actually executes. A7.7 also notes that fetch errors are swallowed because the inner promise is neither awaited nor returned; the prototype leaves that alone, since awaiting it would change download_file's timing and error behaviour.
