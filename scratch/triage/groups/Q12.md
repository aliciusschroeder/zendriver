# Group Q12 (swallowed-cancellation)

queue: fix  |  triage severity: hang  |  triage fix kind: local

## Claim
Bare `except:` / BaseException handlers around awaits swallow asyncio.CancelledError, so wait_for timeouts and task.cancel() are silently ignored (seeded lead)

## Files
zendriver/core/connection.py (_register_handlers), zendriver/core/element.py (Element.click), zendriver/core/proxy.py (UpstreamProxy.open_tunnel)

## Triage fix strategy (a hypothesis, not a requirement)
Catch Exception (not bare except / BaseException) where the intent is to tolerate errors, so CancelledError propagates. Leave sites that already re-raise as they are.

## Triage test approach
Browser-free: cancel/timeout a send whose nested Domain.enable never answers -> the outer task is cancelled promptly instead of continuing; same for Element.click during flash.
