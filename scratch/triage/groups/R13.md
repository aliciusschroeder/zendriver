# Group R13 (hidden-click)

queue: report  |  triage severity: crash  |  triage fix kind: local

## Claim
Element.get_position raises instead of returning None (empty quads / no tree), so click() raises before its JS click on hidden (display:none) elements and the documented 'not visible' fallbacks in mouse_* are dead code

## Files
zendriver/core/element.py (get_position, click, flash, mouse_click/move/drag)

## Triage fix strategy (a hypothesis, not a requirement)
Return None from get_position when there are no content quads (as its except IndexError intended) and avoid self.parent raising for tree-less elements.

## Triage test approach
Real Chromium: click() on a display:none button runs the JS click.

### A8.3: Element.click() raises before clicking when the element has no layout box (display:none, hidden)
- where (may drift): zendriver/core/element.py:click / get_position:432
- finder severity: crash
- claim: `btn = await tab.query_selector('#hid')` for <button style='display:none' onclick=...>, then `await btn.click()`. click() calls the cosmetic `await self.flash(0.25)` before el.click(). flash() calls get_position(). DOM.getContentQuads returns [] (or a 'Could not compute content quads' ProtocolException for detached nodes), and get_position raises a bare Exception('could not find position ...'). Its `except IndexError: return None` can never fire because `quads[0]` is guarded. click() therefore raises and the JS el.click(), which works on hidden elements, never runs. The same broken contract makes the `if not position: logger.warning(...); return` branches in mouse_click, mouse_move, mouse_drag, flash and screenshot_b64 dead code. Those methods raise a generic Exception instead of returning, and screenshot_b64 does not raise the RuntimeError its docstring promises.
- finder evidence (unverified): probe1.py: '[A click hidden] EXC Exception: could not find position for <button id="hid" style="display:none" ...>' and afterwards window.hidClicked = None, so the click never happened.
- finder repro idea: page1.html #hid (display:none, onclick sets window.hidClicked). Call hid.click(), then evaluate window.hidClicked.
